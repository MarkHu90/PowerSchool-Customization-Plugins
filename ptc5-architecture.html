PowerSchool PTC V5 — 家长会预约系统架构

浏览器 → PowerSchool 插件运行时 ↔ 厂商云 PHP 服务 · 预约数据的真实归属

关键架构事实：预约不在 PowerSchool

  • • 数据库扩展中没有 u_ptc5_bookings 表
  • • 预约由 guardianbook.php / adminsignups.php 写入厂商云
  • • 本地仅有 u_ptc5_bookingremarks（教师备注），按 bookingid 关联远端
  • • 座位占用、上限、siblings 规则均在远端执行，仓库内无法审计

外部依赖

  • • www.psugasia.com/webapps/api/ptc/v5/*.php：预约、License、报表、邮件
  • • tz.add-to-calendar-technology.com：时区列表与 ICS VTIMEZONE
  • • SMTP 中继：u_ptc5_settings 中的凭据，由远程服务发信
  • • psugasia.com 不可达时，预约/改约/教师日程/发信全部失效

PowerSchool 侧职责

  • • Custom Page 页面与 *.json 数据端点
  • • 51 条命名查询 + u_ptc5_* 表 CRUD
  • • pagecatalog / permission_mappings / MessageKeys
  • • plugin.xml 字段 ViewOnly 授权 + CDN 白名单
  • • Selection Service 支撑报表的“当前选择”
